# Third-party assets

The site serves these assets locally. No third-party service is required at runtime.

| Asset | Source | License |
| --- | --- | --- |
| Inter font | https://github.com/rsms/inter | SIL Open Font License 1.1, `licenses/Inter-OFL.txt` |
| Newsreader font | https://github.com/google/fonts/tree/main/ofl/newsreader | SIL Open Font License 1.1, `licenses/Newsreader-OFL.txt` |
| Selected Lucide icon paths | https://github.com/lucide-icons/lucide | License text and upstream notices in `licenses/Lucide-ISC.txt` |

The Lucide paths were extracted from the prototype's bundled Lucide v1.17.0 distribution. Only icons used by the interface are included, with appearance controls defined inline. The original font files were converted to WOFF2 without subsetting or changing glyphs. Upstream license notices are retained in `licenses/`.
